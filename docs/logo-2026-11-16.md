# Airfryer times logo

## 定位与设计

面向普通家庭的空气炸锅做法、温度和时间查询工具。品牌保持一个名称和一套标志，不按界面语言或单位配置拆开。

新标志用实心空气炸锅机身、计时旋钮和抽屉把手表达用途。相比原来的细线炸篮与热气，主图形有更完整的轮廓，适合页头、浏览器标签和主屏入口的小尺寸显示。没有添加火焰、勾选章或“实测认证”等新含义。

使用项目原有配色和字体，不从记忆猜色：

- `src/styles/tokens.css` 的 `oklch(52.5% 0.18 26)`，浏览器转换为 `#bc2d2d`。
- 浅色 `oklch(99% 0.005 80)` 对应 `#fdfbf8`，深色文字仍使用项目现有值。
- 名称保持 Airfryer times；DM Sans 与中文系统字体、页面布局和所有业务逻辑保持。

本轮由原生 SVG 几何绘制，没有使用生成式位图或第三方商标素材。设计依据是本网站的既有定位，不声称已完成商标检索。

## 单一主文件

`public/logo.svg` 是唯一编辑源。64×64画布、圆角红底、浅色机身；表盘、分隔和把手为同一几何系统。页头显示32px，整个首页链接至少44px高，并保留原有本地化可访问名称与键盘行为。

运行 `npm run icons:generate` 派生：

| 文件 | 用途 |
| --- | --- |
| `public/logo.svg` | 页头主标志、可缩放下载 |
| `public/logo-mark.svg` | 透明底单色版本 |
| `public/favicon.svg` | 与主文件完全一致的浏览器矢量图标 |
| `public/favicon-16x16.png` / `favicon-32x32.png` | 小尺寸浏览器后备 |
| `public/favicon.ico` | 16/32/48px三种尺寸 |
| `public/icon.svg` | 主屏导出中间文件，不透明方形背景 |
| `public/apple-touch-icon.png` | 180px Apple Touch 图标 |
| `public/icons/icon-192.png` / `icon-512.png` | 192/512px manifest 图标 |

主屏导出在同一机身几何上增加6.25%的安全留白，重要浅色图形完整落在中心80%直径的圆形安全区域内。由平台施加圆角或圆形遮罩；PNG本身四角不透明。favicon保留透明圆角，避免把主屏遮罩直接烘焙进所有版本。

页头、favicon、Apple Touch与manifest链接已同步，图标缓存版本更新为3。manifest仍为browser显示、原start_url和scope，未增加离线或独立应用能力。网站浏览器栏保持暖纸色，不改成大面积品牌红。
