# 地区化版本开发记录

用户已接受内容标准并于 2026-11-13 授权开始开发。目标：用户看得懂、选得对、照着做得下去；保留有依据的腌制和多厨具做法，提前说明条件。采用已评审的暖白、暖红、DM Sans / 苹方 UI。

## 已确认边界

- 在独立分支 `codex/airfryer-regional-app` 开发，不改个人主页、不合并主分支、不部署。
- 中国家常与美国常见使用独立的内容集合；界面语言、地区和单位分别选择并记忆。
- 英文仍是首次进入的默认语言；中文入口默认中国家常与公制，明确选择过的偏好优先。
- 中国内容使用原始摄氏度参考，全程最高 200°C；美国使用最高 400°F 的原始参考。禁止按重量推算时间、静默截温或取最近档。
- 原有美国食品和分享地址保留语义；新增中国做法使用独立地址，不因切语言改变同一地址所指的食谱。
- 单位切换覆盖份量、尺寸、配料、步骤、安全提示；保留来源原文单位但折叠展示并标注。
- 五份已评审样稿接入完整材料、工具、分阶段时间、步骤与完成检查。食物库不限制为五份，也不为凑数收录条件不足的做法。
- 参考整理、结构检查、浏览器验收与实机烹饪验证分别说明；本站尚未做实机烹饪测试。

1. 地区路由、内容模型、单位格式与偏好基础；统一采用同一份原始烹饪事实。
2. 接入五份样稿，审查现有 50 项美国参考，补充中国家常内容与来源记录。
3. 首页、分类、完整详情、地区选择与可见限制，保留搜索、来源、隐私选择、PWA 图标与 GA4 事件。
4. 适当的行为测试、内容校验、构建、中英文与手机浏览器任务验收、Hallmark 独立复核。
5. 提交功能分支与 PR 供 review；没有新的合并部署授权时停在可评审结果。

## 已实现与验收（2026-11-13）

- 中国集合 11 道：奥尔良鸡中翅、先炖后烤蒜香小排、袋装冷冻细薯条、整根烤红薯、孜然烤馒头片、自调蛋液烤蛋挞、炒蒜酱烤茄子、家常烤土豆块、椒盐烤老豆腐、孜然辣味烤香菇、先煮后烤原味玉米。来自独立研究，不把美国条目翻译后冒充中国内容。
- 美国保留原 50 食物与既有 55 条件；新增完整香料腌鸡胸条件。两集合合计 61 食物、67 条件。已有条件的温度、时间、起始状态和 ID 保留。补齐发现的配料、前处理和工具缺口；48 项审查中，基础完整项依据既有来源记录复核，补缺项另查原作者，不声称全部资料都在本轮重新在线核验。
- 中国入口 `/zh`，美国中文入口 `/zh/us`，中国英文入口 `/china`。旧 `/foods/*` 与 `/zh/foods/*` 保留美国语义。中国做法使用独立的 `/china/foods/*` 与 `/zh/china/foods/*`。分类文案也按集合区分。
- 材料、工具、腌制、分阶段时间和额外锅具提前展示；来源资料在后面折叠。中国肉类提供有来源的无温度计家庭观察分支；美国测温依赖提前告知。排骨不把 7 分钟气炸冒充整道菜总耗时。
- 单位选择覆盖操作正文的温度、重量、尺寸与容积。标准量匙/量杯保留体积含义，不将盐擅自换算克数。跨温标明确“等值温度，仅供对照”，可恢复原档位；不强制套用 205°C、不截到 200°C、不外推时间。
- 图标、Apple Touch 图标、搜索、分享、可选统计及来源链接保留。增加 `region_change` 与地区/语言/单位事件维度，原始搜索词仍不发送；本地与预览禁用真实统计。
