# 页面层次与日常食物搜索改进

本次针对目录难以扫读、主要设定不突出，以及常用简称搜不到菜谱的问题。保留既有暖白和红色、DM Sans 与中文系统字体，保持工具页面结构。

## 页面变化

- 目录区突出菜名，并把温度与每批气炸时间分成独立的数值区域；起始条件与必须提前准备的说明完整保留。
- 手机顶部缩短间距、把快捷搜索放入搜索区。375 × 812 首屏能显示第一道菜完整的温度与时间。
- 详情页把气炸设定移到材料和分阶段时间之前，提前提示冷藏腌制、炒锅等前提；材料、阶段与编号步骤分别呈现。
- 工具清单使用原生 details 展开，关闭 JavaScript 仍可展开。其余完整菜谱、安全检查及来源保持可读。

## 搜索变化

- 支持食材简称和省略限定词，例如「鸡翅」找到「奥尔良鸡中翅」、「冷冻薯条」找到「袋装冷冻细薯条」。
- 支持已定义的日常同义词，例如「地瓜／番薯」「土豆／马铃薯」「排骨／小排」，以及目录食材中常见的繁体字、全角输入和标点归一化。
- 英文支持关键词调序，以及按完整词和词长限制的拼写容错，例如 `brocolli`、`frise`。短词限制为一次编辑，七个字母以上最多两次；相邻字母调换计一次。没有加入拼音搜索或通用繁简转换库。
- 分类没有结果、但同一地区的其他分类存在匹配时，可保留关键词切回全部分类。输入法组词期间不执行搜索。
- 快捷词、清空关键词、分类恢复继续沿用现有 GA4 事件，不发送查询原文；重复点击同一快捷词不重复计数。
